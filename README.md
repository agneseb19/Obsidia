# OBSIDIA · Haute Joaillerie

Sito concept per un marchio di gioielli di fantasia: la collezione **Nuit** (cinque anelli in nicchie di ossidiana) e la linea **Lucciole**, con scheda prodotto e carrello simulato.

Progetto di [Agnese Barnaba](https://agneseb19.github.io/), UI/UX Designer e Front-end Developer.

**Versione online:** https://agneseb19.github.io/obsidia/

## Tecnologie
- HTML, CSS e JavaScript, senza framework
- Immagini in AVIF / WebP con alternative JPG
- Layout responsive (desktop, tablet e mobile)

> Marchio, prodotti e prezzi sono di fantasia. Progetto a scopo di portfolio.
